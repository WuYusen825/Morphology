## 4 ext_summary.md §6 的措辞

整体公允：限制都列出来了，也没有把 (A) 写成已被否定。以下三处要改，一处要补。

- **W1 “主要见于跨声符比较”会误导。** 声符内 MH 的点估计是 2.01，与 GEE 的 2.35 相近；区间宽，是因为只有 37 个声符同时有相关的亦声对和相关的普通对。这不说明效应来自声符之间的差异。
  - 建议写：同一声符内比较的点估计相近，但可比的声符少，区间跨过 1。
  - 英文可作：“the within-series estimate is similar in size (MH 2.01) but imprecise, since only 37 series contain related pairs of both kinds”。
- **W2 “许慎本人的标注”说过了。** 应作“最可能出自许慎的标注”（v7 的用语），并注明 X3 是探索性检验。
- **W3 说清楚结果排除了什么。**
  - 被排除的是：只凭意义（按释义编码的意义）决定标注。这种解释预测 OR ≈ 1，数据不支持。
  - (A) 仍能成立的唯一途径是：对同音字对，编码得出的“相关”低估了许慎所见的相关，也就是计划 §4.6 的第二条偏差。X1、X2 缩小了这种可能，但没有排除。
  - 建议写：“意义本身不足以解释标注的语音偏向，除非按释义编码的相关性系统地低估了许慎对同音字对的判断。”这比“不宜写成 (A) 被否定”更具体。
- **W4 要补：初稿 3 的“基字假说”通过了事先写定的检验。**
  - 初稿 3 §5.2（04:03，早于扩大盲编）写道：“It would be contradicted if the test above, run on all labelled pairs and a large sample of ordinary ones, found no difference.”
  - 这个检验在编码前预登记，结果找到了差别，而且新数据单独也重现了。这是论文现在最有力的一点，应当写出。
  - 同时要保留两点：假说是在原结果之后形成的；它的另两项预测（出土文献写法、讀若与声训）尚未检验。所以只能说“通过了一项预先写定的检验”，不能说“得到证实”。
